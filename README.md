# 🧮 Simple Python Calculator

A beginner-friendly calculator built with Python. It supports basic arithmetic operations like addition, subtraction, multiplication, division, modulus, and power. This project was created for practicing Python functions, loops, and error handling.  

## ✨ Features
- ➕ Addition  
- ➖ Subtraction  
- ✖️ Multiplication  
- ➗ Division (with zero-division handling)  
- 🔢 Square (power of 2)  
- % Modulus  

## 🚀 How to Run
1. Install **Python 3** on your system.  
2. Clone this repo:  
   ```bash
   git clone https://github.com/your-username/python-calculator.git
   cd python-calculator
3. Run the script:
    python calculator.py
Choose an operation when prompted:
    +   for Addition 
    -   for Subtraction  
    *   for Multiplication  
    /   for Division  
    ^2  for Square  
    %   for Modulus
Example:
    Enter the 1st number here: 10  
    Enter the 2nd number here: 5  
    Total sum is : 15
